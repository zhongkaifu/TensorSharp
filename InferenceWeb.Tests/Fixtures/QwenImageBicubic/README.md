# Independent Qwen byte bicubic pixels

`reference.json` contains eleven tiny original RGBA/PNG images and expected RGB
bytes generated by **Pillow 12.3.0**, without importing TensorSharp or copying its
resampling implementation. The normal .NET tests consume this embedded file
offline; no Python, network, model, or native backend is required.

The reference pipeline composites RGBA over opaque white with Pillow's
`Image.alpha_composite`, converts to RGB uint8, and resizes with
`Image.Resampling.BICUBIC`. Pillow rounds/clamps the horizontal uint8 pass before
the vertical pass. The alpha cases include 0/1/64/127/128/192/254/255 opacity and
also exercise compositing without resizing. The opaque cases cover upscaling,
strong downscaling/antialiasing, mixed axes, single rows/columns, edge/corner
impulses, no resize, and a fixed red-rectangle/black-ink card. The card uses fixed
bitmap shapes, avoiding platform font dependencies.

Primary references:

- [Transformers v5.16.1 Qwen2-VL processor](https://github.com/huggingface/transformers/blob/v5.16.1/src/transformers/models/qwen2_vl/image_processing_qwen2_vl.py)
  declares bicubic image resizing.
- [Pillow 12.3.0 Resample.c](https://github.com/python-pillow/Pillow/blob/12.3.0/src/libImaging/Resample.c)
  implements quantized coefficients and byte-domain passes.
- [Pillow 12.3.0 AlphaComposite.c](https://github.com/python-pillow/Pillow/blob/12.3.0/src/libImaging/AlphaComposite.c)
  defines the independent rounded alpha reference used here.
- [Unchanged llama.cpp 4ebdf2c74 image preprocessor](https://github.com/ggml-org/llama.cpp/blob/4ebdf2c74acce30883d8e34b7c70b3eb8146f2fe/tools/mtmd/mtmd-image.cpp)
  is the existing comparison implementation. It is neither changed nor imported
  by this fixture generator.

Reproducibility check with the pinned Pillow version:

```powershell
python -X utf8 -B eng/validation/generate-qwen-bicubic-reference.py `
  --output InferenceWeb.Tests/Fixtures/QwenImageBicubic/reference.json --check
```

The generator refuses to overwrite an existing oracle. Updating reference pixels
requires deliberate fixture regeneration/review. The tests assert every RGB byte
through the CPU helper and both public processor overloads, plus channel-first
`[-1,1]` normalization. These pixel tests do not establish vision-embedding parity,
model answer quality, GPU execution, or performance.
