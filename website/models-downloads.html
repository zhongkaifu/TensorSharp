🧩

Multimodal models need a projector (mmproj) file. Download the matching file and pass its exact path with --mmproj. The server never auto-detects a chat model's projector (Qwen-Image-2.1's editing projector is the exception: both hosts find it beside the DiT, see its row above). The CLI, given an image without --mmproj (or, for Gemma 4 and Nemotron, an audio clip or video), looks beside the model only for the file names that family declares — for example *mmproj*.gguf for Qwen 3.8 Flash Next and GLM 5.x, deepseek41.vision.gguf for DeepSeek V4.1, the two Bonsai2 projector names — and never for the DiffusionGemma vision shard.

🔤

The MiniMax-H3 text-encoder GGUF carries no tokenizer. Auto-download can only fill in options that are flags, and the tokenizer is not one, so no config file will fetch it for you. Take vocab.json and merges.txt from the processor/ folder of MiniMaxAI/MiniMax-H3 and put them beside the encoder, or point TS_VIDEO_TOKENIZER at the folder that holds them.

📦

config/minimax-h3-fl2va.json and config/minimax-h3-ref2va.json name all four networks, so the first run fetches them (~35.5 GB in total) and later runs reuse them. Only the model entry differs between the two files, so the text encoder and both VAEs download once and are shared — the second checkpoint costs one denoiser, not a second full set. Each network is also loaded and released in turn, so peak VRAM is the largest single network and not the sum of the four.
