Native.cs ccd45805, project 3f09b1cd. The linked Probe Program.cs 14ccbf38 and

an operator-owned exclusive window; CPU commands below do not use CUDA/models.

  generally based on numeric partition consistency, throughput or aggregate scores.
* The strict same-slot/partition numeric checks do not establish model-answer

Interpretation and limits:
* No --execute writes a plan and performs CPU contract checks only. It is NOT_RUN
  for CUDA, models and GPU numerical validation. Default phase is all.
* Component checks Q81 bytes/scales and complete outputs against independent
  explicit existing N8/tail calls with guarded buffers/offsets. N1/N8 differences
  remain strict FAIL. This is one comparison per fixture, not component A/A or
  proof of serving eligibility. Model/native/source identities remain required.
* Partition compares VerifyN2x8 and separate VerifyN1x8 on the same two physical
  slots, prefix7/equal maxKeys, with reset A/A and ABBA/full F32/drawn/features.
  It re-Verifies N2 before Commit after N1 overwrote verify buffers, and uses the
  same DecodeBatch2 shape for both teacher arms. Unchanged head/attention shape
  effects can still cause genuine strict failures; no tolerance is substituted.
* Guard v2 paints and inspects uint32 bits before/after transfer, preserving all
  three 16-word tails. The prior sNaN float-initialization failure remains in
  historical evidence. Passing CPU guard tests does not prove a GPU result.
* Mixed keeps the 4096+64, 9-slot schedule and 38 F32 records/292 vocab rows.
  Cross-flag comparison covers two last-prefill full-vocabulary rows, NOT every
  prefill position or full recurrent state. A baseline without --mixed-reference
  can finish capture but exits1/quality=false with cross-flag NOT_RUN. Preserve it
  and continue independent candidate arms; do not reclassify it as numeric PASS.
* Host role/dtype/range/API counters are submitted calls, not a GPU profiler.
  The immutable Main policy adds a separate cache fingerprint when enabled.
  On current Main, TRACE=0 leaves the dispatch dictionary unallocated and avoids
  the prototype's Q81Chunks arrays; TRACE=1 intentionally observes submissions.
  Program.cs retains the executed prototype's old embedded limitation about
  force1/TRACE0 allocations to preserve its exact source SHA. That sentence
  describes the old prototype, not the current Main production implementation.
* Candidate ImageSha256 may be null. Located-file hashes, loader/assembly/source
  and module/function metadata are provenance, not a driver-provided image hash.
* Numeric PASS is not a performance, serving quality, or unrestricted model
  correctness claim. Legacy A4 and role-Q81 verification intentionally differ.
