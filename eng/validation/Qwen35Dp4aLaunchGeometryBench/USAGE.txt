Before each role's ABBA the original Q81 kernel is checked with two distinct
payload poisons; every Q81 byte/F32 scale, guard and output is checked again after
each half. The primary event interval includes ORIGINAL Q81 quantization followed
by GEMV every iteration. No RMSNorm/embedding/model/serving latency is included.
The old prequantized GEMV-only experiment is not directly comparable in absolute
latency. The original96 strict fields, ordering and FP32 criterion are unchanged.

Warm repeats the same matrix, default3 iterations per half. Sweep forces1 and
executes >=2× actual driver L2 bytes using asm volatile ld.global.cg.u32, checksum
and synchronize outside the event. It evicts all data including F32 input; the
event's quantizer rewrites packed activations. This is eviction-control, not a
physical-cold guarantee or weights-only experiment. Each half still gates bits.
Five ABBA rounds/role are correlated micro observations; no model quality or
end-to-end gain follows from synthetic PASS or a resource/occupancy observation.

Original sealed Int8MMA/Rows/ScheduleR3 files are read-only dependencies. Local
source generation/CPU mock/host syntax tests are not native compilation or GPU
