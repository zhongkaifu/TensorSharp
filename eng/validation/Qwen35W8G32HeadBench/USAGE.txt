Standalone synthetic W8G32 head experiment. No production or ggml changes.

Build defaults to source generation only (does not call nvcc or a GPU):
  python3 eng/validation/Qwen35W8G32HeadBench/build.py --out artifacts/w8-source
Offline CUDA compilation, on ROOT's authorized machine only:
  python3 eng/validation/Qwen35W8G32HeadBench/build.py --out artifacts/w8-built --compile --nvcc /usr/local/cuda-13.2/bin/nvcc
Default plan (no GPU; fresh data name required):
  python3 eng/validation/Qwen35W8G32HeadBench/run.py --build artifacts/w8-built --name plan --data /dev/shm/ts-w8-plan
Explicit synthetic strict gate:
  python3 eng/validation/Qwen35W8G32HeadBench/run.py --build artifacts/w8-built --name strict --data /dev/shm/ts-w8-strict --execute
Warm and all-data/L2 eviction-control modes, separate fresh evidence/data:
  python3 eng/validation/Qwen35W8G32HeadBench/run.py --build artifacts/w8-built --name warm --data /dev/shm/ts-w8-warm --bench --execute
  python3 eng/validation/Qwen35W8G32HeadBench/run.py --build artifacts/w8-built --name sweep --data /dev/shm/ts-w8-sweep --bench --cache-sweep --iterations 1 --execute

ROOT owns VM/GPU lease and execution; the standalone runner does not acquire a
remote lease or SSH. No native/CUDA build is implied by local CPU/source tests.
Actual ELF resources, stack/spills, occupancy and hardware are recorded. Driver
launchability >=1 CTA is required, with no assumed two-CTA/register target.

Numeric contract was frozen before implementation: numeric-contract.json SHA
03fc1a0681beb3a4a0d9ebfdde3980d670b49534008db7e3284c3bc551875f7e.
Stored signed int8 codes plus finite F16 scales/32 and BF16-rounded activation
are the oracle domain. BF16 subnormal activation and nonfinite input/scales are
rejected. F16 subnormal/signedzero/negative/finite-edge scales are covered.
The independent FP64 reference and sumAbs define the fixed FP32 gamma_n plus
BF16-rounding bound. This is a new datatype/activation contract, NOT TS Q6_K
bit equivalence or model-quality evidence. Integer/power-of-two small cases
add exact BF16 bits; every path requires A/A fullbits and two output poisons.

There are 32 unique strict shapes: each T=1,7,8,14,16,28,32,33 has three small
cases (17x32 exact; 33x160 row/K padding; 15x512 scale/code edges), plus the
real head [248320,5120]. Independent CPU FP64 and exact group-FMA FP32->BF16 checks all 24 small cases; the
GPU literal-FP64 reference checks all 32. Official upstream only covers the
8 real shapes. All full reference.f64, sumAbs.f64, input.f32/input.bf16 and
SIMT/owned/official BF16 outputs are retained and independently checked by
run.py; successful A/A extra passes and device guards are producer in-memory
checks, not independently persisted GPU snapshots. Failed cases preserve raw.

The owned CUDA is independently authored using public m16n8k16 PTX fragment
rules. Official baseline includes exact e600a7d9 upstream six-header closure,
original schedules/launch bounds/minBlocks/PDL/BF16 stores, and the complete
applicable license/NOTICE/provenance files in upstream/. Its manifest is
66b48ffe40fc820ac4cfab5c9cfcc32ee93042514c1944dafd7a16a44f2e7c9c.
It is a freshly compiled source baseline, not the historical Ignis executable
or a reproduction of its end-to-end tokens/s. Small tails use owned/SIMT only.
All kernels in one translation unit use identical explicit compiler flags.
Naive SIMT is a functional/same-dtype control, never a strong speed baseline.
The primary performance comparison is owned vs unchanged official source.

All 32 unique strict shapes pass before any timed event. Each real timed
shape is independently gated again. Each pair has >=10 ABBA rounds, all four
halves compare the entire BF16 output against that arm's strict A/A result
and rerun numeric/guards. Primary events include F32->BF16 cast + full W8
matmul + BF16 store; no cached activation prepack is excluded. The all-data
sweep performs volatile ld.global.cg full reads of >=2x actual driver L2,
verifies per-block uint64 checksums/counts and synchronizes before each half.
It is outside the event and not a physical-cold or weights-only guarantee.
Sweep forces iterations1; default warm also uses iterations1. No argmax or
matmul-only timings are silently substituted for complete-pipeline values.

The synthetic full head has codes1271398400B + scales79462400B =1350860800B
(1288.28125MiB). This exceeds TS Q6_K1042944000B by307916800B (293.65234375MiB)
and is NOT lossless Q6 repacking. Per-case GPU allocations additionally include
inputs, three guard-padded outputs/reference buffers and >=2xL2 if requested;
no model-memory-fit claim. Actual Ignis artifact bytes are NOT loaded here.
SHM full-array data is 764400476B (~729.0MiB) per successful strict run; there
are no measurement-time FUSE writes. Archive/hash/transfer after completion.
