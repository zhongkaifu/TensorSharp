# DeepSeek V4.1 Flash 1017 perf rows for ONE engine process (TensorSharp.Cli --bench-suite, or
# run-multinode-case.py --kind suite --suite-file). The S9 part 2 shapes: random tokens, decode 128, 4 runs
# (medians of runs 2-4); the seed is --bench-random-tokens' own, so the ids are S9's.
#
# Cold rows first. 'cold' drops the Engram tables from every node's page cache before the row (inside the
# processes, verified with mincore); later runs of a cold row warm up as they go, as in an S9 cold process.
# A warm row right after the cold row of the same shape replays its ids, so its rows are cached (S9's warm method).
# check=0 skips the untimed greedy chain after each row (one more full prefill); identity is the probes' job.
# Needs TS_DSV41_ENGRAM_DEVICE=0 (host-mapped tables) and TS_DSV41_ENGRAM_WARM=0 (no background warm).
# The defaults run the parallel Engram reads with MADV_RANDOM only. The opt-in switches go in the process environment,
# one setting per process, for an A/B inside one build: TS_DSV41_ENGRAM_OWNER=balance (one table per node, needed for
# a warm steady state on the 1017), TS_DSV41_ENGRAM_PREFETCH=1, TS_DSV4_ASYNC_SEND=1; TS_DSV41_ENGRAM_THREADS=1 is S9.
